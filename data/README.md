# Data Notes

This directory contains only small examples for smoke checks. Full source data are not redistributed in this review repository.

The full benchmark reconstruction expects public data from:

- ACNet
- MoleculeACE
- ChEMBL
- BindingDB

Large raw tables, release dumps, pretrained embedding caches, and split-index matrices are omitted to keep the anonymous review repository lightweight. Frozen table outputs and audit summaries are provided under `review_artifact/`.
